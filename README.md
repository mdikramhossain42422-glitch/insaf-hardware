# 🛠️ Insaf Hardware (insafhardware.com)

A modern, fully responsive e-commerce web application designed for a hardware and industrial supply store. Built with **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**, featuring a rugged industrial aesthetic tailored for Bangladeshi customers with BDT (`৳`) pricing, live search, category filtering, and an interactive shopping cart.

## ✨ Key Features

* **Industrial UI Design:** Styled with a professional slate, charcoal, and safety-orange color palette.
* **Dynamic Catalog & Categories:** Filter instantly between Power Tools, Hand Tools, Plumbing, Electrical, Paints, and Safety Gear.
* **Live Search & Sorting:** Real-time search functionality with sorting options (Price: Low to High, High to Low, Featured).
* **Interactive Shopping Cart:** Slide-out drawer with quantity management, subtotal calculation, and automatic free delivery threshold checks (Free delivery over ৳5,000).
* **Checkout Simulation:** Built-in modal supporting Cash on Delivery (COD) and mobile payment simulation (bKash/Nagad).
* **Fully Responsive:** Optimized for seamless viewing on mobile phones, tablets, and desktop computers.

## 🚀 Quick Start & Deployment

You can test this website locally or host it online for free in under 2 minutes:

### 1. Run Locally
1. Clone or download this repository to your computer.
2. Make sure your main file is named `index.html`.
3. Double-click `index.html` to open it directly in your web browser.

### 2. Deploy Free on Netlify
1. Go to [Netlify](https://www.netlify.com/) and create a free account.
2. Drag and drop your project folder directly onto the Netlify dashboard drop zone.
3. Your site will be live instantly with a free `.netlify.app` URL!
